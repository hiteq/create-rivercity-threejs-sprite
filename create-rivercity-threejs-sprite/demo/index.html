⚡ 5-Line Three.js 2.5D Integration

Integrate any Kunio-kun / River City style character into Three.js with nearest-neighbor crispness and rock-solid ground contact:

const texture = new THREE.TextureLoader().load('sheet.png');
const player = new SpritePlayer(manifest, { initialAnimation: 'idle' });
const adapter = new ThreeSpriteAdapter({ THREE, manifest, texture, player });
scene.add(adapter.mesh);
adapter.mesh.position.set(worldX, 0, worldZ); // Grounded Y=0

// In your render loop:
adapter.update(deltaMs);

⚖ The Sole Anchor Rule

Never use bounding-box centers for sprite alignment! An extended punch fist widens the sprite frame by 8 pixels. Centering on the bounding-box yanks the character body backwards on strike.

In this runtime, every frame anchor [ax, ay] is fixed precisely at the ground contact point between the feet (16, 39). Horizontal mirroring pivots around ax, guaranteeing zero positional drift when changing direction.

📋 Provenance & Accuracy Tiers

Strict distinction must always be maintained between:

  • Verified Source Data: Extracted from ROM CHR dumps or emulator frame-advance logs (FCEUX, Mesen).
  • Reconstructed / Estimated Data: Ripped sheets or fan-assembled animations with estimated 60Hz tick durations.
  • Original Artwork: Newly authored characters adhering to Kunio-kun visual grammar and palette constraints (CC0).
